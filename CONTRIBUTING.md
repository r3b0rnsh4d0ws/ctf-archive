# Contributing

Thanks for helping improve the R3B0RNSH4D0WS public archive.

## Before opening a pull request

1. Verify the challenge result and flag format.
2. Write a reproducible explanation with the key insight, commands, and lessons.
3. Do not include session cookies, tokens, credentials, private infrastructure, or unreleased challenge material.
4. Do not add raw third-party challenge files unless redistribution rights are confirmed.
5. Run the archive validation checks locally where possible.

## Quality standard

A solve is not complete when only a flag exists. The public writeup should make the path understandable to another learner and preserve useful negative results without exposing private data.
