# Security Policy

## Reporting a vulnerability

Please report security issues privately through the repository’s GitHub Security Advisory form when available. Do not open a public issue containing credentials, session cookies, private infrastructure, exploit details against live systems, or unpublished challenge material.

## Scope

This repository is a public educational archive. Do not test GitHub, the organization, third-party CTF platforms, or infrastructure without explicit authorization.

## Publication boundary

The public repository excludes session cookies/tokens, credentials, raw third-party challenge files, rejected flags, and incomplete/private work. If sensitive material is accidentally published, rotate it first and contact the repository maintainers promptly.
